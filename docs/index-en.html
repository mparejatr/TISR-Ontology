Abstract

The TISR-Ontology has been developed to address the growing need for structured and interoperable information within the domain of urban tourism. In increasingly connected cities, tourism management requires the integration of heterogeneous data sources to provide more personalized, dynamic, and efficient services to visitors.

TISR-Ontology: Description back to ToC

The purpose of this ontology is to establish a tourist map of cities of interest, providing a knowledge structure that enables: • Improving the organization and accessibility of tourism information. • Supporting automatic personalized recommendation mechanisms. • Facilitating the integration of open and heterogeneous data sources. • Promoting interoperability between smart tourism service platforms. The main use case consists of a smart tourism system that offers personalized recommendations to visitors, such as: • Suggesting relevant events based on user location and preferences. • Recommending hotels based on price range and user ratings. • Guiding users in selecting tourist attractions according to their interests.
